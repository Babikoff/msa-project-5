### <a name="_qmphm5d6rvi3"></a>**Решение**

Для простоты начальной версии предлагается реализовать отправку оповещений по электронной почте через внутренний сервер.

Общая схема работы системы оповещений будет такая:

```Prometheus (rule evaluation)
        │  alerts (HTTP POST)
        ▼
Alertmanager ─── SMTP ───► Mailhog (catches email, web UI at :8025)
```

Для отправки оповещений выбран **Prometheus alertmanager**.
