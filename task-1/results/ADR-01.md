### <a name="_qmphm5d6rvi3"></a>**Решение**

Для решения данной задачи предлагается использовать **Apache Airflow**. В таблице ниже обосоновывается соответствие данного решения функциональным требованиям.

|**№**|**Требование**|
| :-: | :- |
| F1 | Возможность ветвления процессов - есть: через BranchPythonOperator, добавления условных операторов через BranchPythonOperator и Sensor-ы, event-triggers через Trigger Rules |
| F2 | BigQuery - есть: BigQueryInsertJobOperator, GCSToBigQueryOperator, BigQueryToGCSOperator |
| F3 | Redshift - есть: через RedshiftSQLOperator, RedshiftDataOperator, S3ToRedshiftOperator |
| F4 | Kafka - есть: через ProduceToTopicOperator, ConsumeFromTopicOperator |
| F5 |Spark - есть: через SparkSubmitOperator, SparkJDBCOperator, SparkSqlOperator |
| F6 | Есть: fallback- через trigger_rule="all_failed" или "one_failed", retry - через параметр retries PythonOperator |
| F7 | Email - есть |
| F8 | Стандртная установка как приложения есть везде, в Google Cloud, Microsoft Azure, AWS есть дополнительные возможности |

Таким образом видно, что предлагаемое решение покрывает все требования. Также Airflow рассчитан на высокие нагрузки, что и требуется в данном проекте.
